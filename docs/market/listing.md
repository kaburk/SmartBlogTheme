## 説明概要（一覧画面・200文字以内：160文字）

```
baserCMS5.4以上向けの、白地にモノクロのすっきりしたブログテーマです。記事の一覧は左にアイキャッチ・右にタイトルと抜粋が並ぶ1列の形で、目次・読了時間・コードのコピー・ライト／ダークの切り替えを備えます。配色はテーマ設定の4色で変更でき、見本の記事・固定ページ・お問い合わせフォーム付きの初期データがあります。
```

## 説明情報1

**説明見出し1**：このテーマについて

**説明詳細1**（エディタの「ソース」に貼る）

```html
<p>SmartBlogTheme は、個人のブログのための、白地にモノクロのすっきりしたブログテーマです。レイアウトは1列で、記事の一覧は左にアイキャッチ・右にタイトルと抜粋が並ぶ行の形です。カテゴリはアイキャッチの左上にラベルで表示し、ウィジェットは本文の下に並びます。</p>
<ul>
<li>記事の詳細：目次（本文の上で開閉）、読了時間の目安、投稿日・更新日、シェア、前後の記事、関連記事、コメント</li>
<li>一覧：アイキャッチ → 本文の最初の画像 → 「色の枠＋カテゴリ名」の順で表示する行の形のカード（スマホは縦積み）、番号つきのページ送り</li>
<li>本文：BurgerEditor のブロックでも、通常のエディタの HTML でも同じ見た目。コードブロック（等幅・横スクロール・コピーボタン・言語名）、表、引用、補足の囲み</li>
<li>ライト／ダークの切り替え。配色モード（OS に合わせる／ライト／ダーク）と切り替えボタンの有無は、テーマ設定で選べます</li>
<li>テーマ設定の4色（メイン／サブ／リンク／ホバー）で配色を変更できます。どの色にしても文字が読みやすいよう、文字の濃さと白黒を自動で調整します。ロゴもテーマ設定で変更できます</li>
<li>お問い合わせフォーム（入力 → 確認 → 完了の3画面）、サイト内検索の結果画面、ブログを横断したタグの一覧、アイキャッチ付きの RSS、広告の枠（ウィジェットエリア）</li>
<li>初期データ：見本のブログ一式（default）、ページ送りの確認用（test：記事40本）、最小構成（empty）</li>
<li>レスポンシブ（PC／スマホ）、印刷用の CSS、prefers-reduced-motion 対応</li>
</ul>
```

## 説明情報2

**説明見出し2**：動作環境とインストール

**説明詳細2**

```html
<h4>動作環境</h4>
<ul>
<li>baserCMS5.4以上</li>
<li>ブログ（BcBlog）が有効であること。BurgerEditor（BcBurgerEditor）は任意です</li>
<li>最新の Chrome・Edge・Safari・Firefox（CSS のコンテナクエリ・:has()・color-mix() を使っています）</li>
</ul>
<h4>インストール</h4>
<ol>
<li>ダウンロードした zip を解凍し、フォルダ名が「SmartBlogTheme」であることを確認して plugins フォルダに配置します（管理画面からのアップロードも可能です）</li>
<li>管理画面 &gt; テーマ管理 で SmartBlogTheme を適用します</li>
<li>同じ画面で初期データ「default」（見本のブログ）・「test」（ページ送りの確認用）・「empty」（最小構成）のいずれかを読み込みます</li>
</ol>
<p><strong>初期データを読み込むと、ユーザー以外のデータ（固定ページ・ブログ・メールフォーム・ウィジェットなど）は初期化されます。運用中のサイトでは読み込まないでください。</strong></p>
```

**説明画像2**：`sp.png`（スマホ：トップ／記事の詳細／記事の詳細のダークモード）

## 説明情報4

**説明見出し4**：コードブロックと制限事項

**説明詳細4**

```html
<p>BurgerEditor では <a href="https://github.com/kaburk/BgeAddonSyntaxHighlight" target="_blank">BgeAddonSyntaxHighlight</a>（色分け・行番号・コピー）と <a href="https://github.com/kaburk/BgeAddonMarkdown" target="_blank">BgeAddonMarkdown</a> の本文も、同じ見た目で表示します。通常のエディタでは &lt;pre&gt;&lt;code class="language-php"&gt;…&lt;/code&gt;&lt;/pre&gt; と書くと、等幅の枠・言語名・コピーボタンが付きます。</p>
<h4>制限事項</h4>
<ul>
<li>baserCMS の初期データは画像ファイルをコピーしないため、見本の記事のアイキャッチは空です（カードには本文の最初の画像を表示しています）</li>
<li>初期データを読み込むと、記事の投稿日は見本の日付に戻ります（ブログは読み込み時に投稿日を「今」にするため、テーマで戻しています）</li>
<li>広告の枠は、ウィジェットエリアを名前（「広告：記事の上」など）で探して表示します。初期データを使わずにテーマだけを適用したときは、同じ名前のウィジェットエリアを作ってください</li>
</ul>
```
